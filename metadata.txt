name=Subtypes and Domains Manager
qgisMinimumVersion=3.22
supportsQt6=True
description=ArcGIS-style Subtypes and Domains for GeoPackage, SpatiaLite and File Geodatabase layers.
about=Define coded-value and range Domains, and Subtypes with a different domain and default value per field for each subtype, then apply them to QGIS layers as form widgets, constraints and default values. The definitions are stored inside the data file (GeoPackage, SpatiaLite or File Geodatabase) so they travel with it, and a validation report finds existing values that break the rules. They are enforced inside QGIS; ArcGIS does not read them.

changelog=0.2.9 - QGIS 4 (Qt6) support enabled; stable release. 0.2.8 - Small integer ranges (e.g. 1 to 5) appear as a drop-down list and can be mixed with coded domains on the same field. 0.2.7 - Editing integer range domains works; a range linked to a subtype shows a number spin box and a clear message with the allowed range. 0.2.6 - A domain set for one subtype now appears only for that subtype. 0.2.5 - Explains exactly why a field is missing (virtual field, unsaved edits, edit mode); fields saved while still in edit mode are picked up. 0.2.4 - Fields added in QGIS are seen right away (File Geodatabase kept them hidden), Refresh fields button, warning for unsaved fields, rule field lists rebuilt when the subtype field changes. 0.2.3 - A rule can no longer be put on the subtype field itself (clear message instead of a silently ignored domain). 0.2.2 - Diagnostics report, fresh code after upgrading without restarting QGIS, errors written to the Log Messages panel, QGIS 4 enum compatibility. 0.2.1 - Subtype-dependent default values also work for fields stored before the subtype field. 0.2.0 - Setup is applied automatically whenever layers of a configured file are loaded or a project is opened (fixes File Geodatabase / GeoPackage not showing it); domain lists are never empty. Tested on real QGIS 3.34 / GDAL 3.8 for all three formats. 0.1.2 - Detailed Apply report (matched layer source and widget per field), SpatiaLite-provider layers recognised, errors shown instead of silent failure. 0.1.1 - Subtype field list shows integer and decimal fields with their detected type, plus the raw field types read from the file. 0.1.0 - First release: coded value and range domains, subtypes with per-subtype domains and default values, apply to layers, validate data. GeoPackage, SpatiaLite and File Geodatabase.
